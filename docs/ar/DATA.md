# البيانات والاستيراد

## ملفات المصدر

ملفات TXT موجودة في:

```text
src/data/raw/
```

السكربت يكتشف جميع ملفات `.txt` تلقائيًا، لذلك لا يحتاج إلى معرفة أسماء `p1` إلى `p24` مسبقًا.

كل سجل يتكون من سبعة أسطر غير فارغة:

```text
رقم المصدر
اسم الجامعة / القسم
الدرجة الكلية
المعدل
الكود
الفرع
الجنس
```

لتوليد البيانات:

```bash
bun run data:import
```

الناتج:

```text
src/features/admissions/data/admissions.raw.json
```

لا تعدّل ملف JSON يدويًا؛ عدّل ملفات TXT ثم شغّل الاستيراد من جديد.

## الفلاتر الديناميكية

خيارات الفرع والجنس تأتي مباشرة من البيانات. لذلك يظهر `علمي` أو `ادبي` أو `مهني` أو `فنون` فقط إذا كان موجودًا فعليًا، ولا توجد قيم `احيائي` أو `تطبيقي` ثابتة من النسخة القديمة.
