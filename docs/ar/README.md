# نظرة عامة على المشروع

هذا المستودع هو إعادة بناء حديثة لتطبيق Gatsby/Ant Design القديم مع الحفاظ على سير العمل الأساسي:

1. تحميل بيانات القبول من ملف JSON محلي مولّد.
2. الفلترة حسب المعدل والفرع والجنس أو البحث بالنص.
3. اختيار ما يصل إلى 50 قسمًا.
4. الانتقال إلى صفحة ترتيب الاختيارات.
5. الترتيب بالسحب والإفلات أو باستخدام أدوات الترتيب السريع.
6. طباعة الترتيب النهائي أو مشاركته عبر واتساب وتيليغرام.

## المزايا

- واجهة عربية وإنجليزية مع RTL/LTR تلقائي.
- الوضع الفاتح والداكن ووضع النظام.
- جدول لسطح المكتب وبطاقات مخصصة للموبايل.
- الفروع والجنس تُستخرج من البيانات الفعلية وليست قيمًا قديمة ثابتة.
- ترتيب حسب المعدل من الأعلى إلى الأقل.
- ترتيب حسب المحافظات/المدن العراقية مع إمكانية كتابة أي مدينة أو قضاء يدويًا.
- ترتيب المدينة لا يحذف أي اختيار ويحافظ على ترتيب العناصر داخل كل مجموعة.
- مشاركة عبر واتساب وتيليغرام.
- طباعة تستخدم `VITE_APP_URL` بدل رابط الموقع القديم.
- دعم PWA والعمل بعد تحميل الأصول.
