# النشر

## إعداد رابط الموقع

انسخ `.env.example` إلى `.env` ثم ضع الرابط العام:

```env
VITE_APP_URL=https://your-public-domain.example
```

يُستخدم هذا الرابط في الطباعة والمشاركة. أي متغير يبدأ بـ `VITE_` يكون ظاهرًا للمتصفح، لذلك لا تضع أي أسرار داخله.

## بناء نسخة الإنتاج

```bash
bun install
bun run build
```

أمر البناء يعيد استخراج البيانات مباشرة من `public/admission-minimums.pdf` ويتحقق منها ويولّد JSON قبل تشغيل Vite.

بعد ذلك انشر مجلد `dist/` على أي استضافة Static. تأكد أن الاستضافة تعيد المسارات غير الموجودة إلى `index.html` حتى يعمل مسار `/selection` عند فتحه مباشرة.
